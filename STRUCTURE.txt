Feature Summary
===============

SENSORS (12):
  • Connected Clients - Number of network devices
  • CPU Usage - UDM Pro Max CPU percentage
  • Memory Usage - UDM Pro Max memory percentage
  • Uptime - System uptime in seconds
  • WAN IP Address - Public IP address
  • WAN Download Speed - Current download Mbps
  • WAN Upload Speed - Current upload Mbps
  • WAN Latency - Network latency ms
  • WAN Download Total - Total bytes downloaded
  • WAN Upload Total - Total bytes uploaded
  • LAN Download Total - Total LAN bytes received
  • LAN Upload Total - Total LAN bytes transmitted

DEVICE TRACKERS:
  • Automatic discovery of all network clients
  • Per-device attributes (MAC, IP, hostname, signal, etc.)
  • Presence detection (home/away)
  • Connection type (wired/wireless)
  • Bandwidth usage per device
  • WiFi network and signal info

DASHBOARD EXAMPLES:
  • Basic dashboard with essential metrics
  • Advanced dashboard with graphs and trends
  • Both include device tracking views

AUTOMATION EXAMPLES (15+):

Installation Options
====================

OPTION 1: Automated Install
  ./install.sh

OPTION 2: HACS (Once Published)
  HACS → Integrations → Custom Repos → Add URL

OPTION 3: Manual Copy
  cp -r custom_components/unifi_network_pro /config/custom_components/

OPTION 4: Docker Volume Mount
  docker cp custom_components/unifi_network_pro container:/config/custom_components/
